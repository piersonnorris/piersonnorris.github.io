      What this is, exactly. A published snapshot of a real Obsidian vault, produced by tools/obsidian-sync.js --public and committed to the site's repo. This first snapshot is the site's own docs/ folder — every file in it was already public in that repo, so the page shows you nothing the repository didn't. It is read-only by design: writing happens in Obsidian. It is a snapshot, not live sync — a static site cannot read a folder on disk, so refreshing means running the command again. Notes opt out with publish: false, and a scrubber refuses to publish anything that looks like a dollar figure, an address or a key. The private, encrypted vault still lives behind /notes/; the curated version of what I've learned is the Atlas.
